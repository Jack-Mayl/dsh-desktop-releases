# dsh-desktop-releases

[DeepSeek Harness Desktop](https://github.com/deepseek-ai/deepseek-harness) 的 Windows 安装包发布仓库。

## 下载

到 [Releases](../../releases) 页面下载最新的 `DeepSeek Harness-x.y.z-x64-setup.exe`。

## 特性

- Electron 桌面壳 + 内置 dsh 引擎（首启自动解压，无需安装 Node.js）
- 便携 Node 运行时
- 自动更新：App 启动时及每 4 小时检查新版本，增量下载后提示安装

## 更新日志

见各 Release 页面。
